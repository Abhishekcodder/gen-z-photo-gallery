# gen-z-photo-gallery

A modern, interactive photo gallery designed for Gen Z with smooth animations, dark mode, and responsive design.

## Features

- **Dynamic Grid Layout:** Seamlessly displays images in a modern, responsive grid.
- **Dark Mode First:** Sleek dark interface optimized for vibrant media contrast.
- **Smooth Micro-Interactions:** Subtle hover effects and modal lightboxes for an engaging user experience.
- **Mobile-First Design:** Fully optimized across desktop, tablet, and mobile displays.

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Styling & Icons:** Modern CSS Flexbox/Grid, Lucide Icons
